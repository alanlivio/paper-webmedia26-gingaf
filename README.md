# paper-webmedia26-gingaf

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](./LICENSE)

Website for the paper **gingaf: A Cross-Platform Architecture to Execute Ginga-NCL and Ginga-HTML5 Applications**, published at **WebMedia 2026** (Proceedings of the 32nd Brazilian Symposium on Multimedia and the Web).

- `latex/` — LaTeX source
- `slides/` — presentation slides using Marp
- `website/` — static webpage using Zensical

Do `make help` to see all available commands. The deployment to GitHub Pages is handled by [deploy.yml](.github/workflows/deploy.yml).
