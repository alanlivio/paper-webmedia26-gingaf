# paper-webmedia26-gingaf

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](./LICENSE)

Website for the paper **gingaf: A Cross-Platform Architecture to Execute Ginga-NCL and Ginga-HTML5 Applications**.

- `latex/` — LaTeX source
- `website/` — static webpage using Zensical

At `website`, do `make help` to see all available commands. The deployment to GitHub Pages is handled by [deploy.yml](.github/workflows/deploy.yml).
